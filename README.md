# VirtualMouse
![image](https://github.com/user-attachments/assets/76a7b5ad-153d-422e-9e32-c12d48f0def4)
Using a hand tracking library I was able to make a code that when the thumb and pointer finger's distance is less then 20 pixels it would click, assentialy creating a virtual mouse.
I intend on adding scrolling motion and left-clicking as-well.
